# CS-472

## Running the React Native Client

1. Navigate into the client directory:

   `cd client`

2. Install dependencies:

   `npm install`

3. Start the Expo development server:

   `npx expo start`

4. Click the web link to see the app running in your browser.

## Testing on a Physical Device

1. Download Expo Go on your phone. This works on both iOS and Android.

2. Create an account at Expo.dev.

   I recommend creating a normal username/password instead of using the "Log in with Google" option.

3. Navigate into the client directory:

   `cd client`

4. Log into Expo from the terminal:

   `npx expo login`

5. Log into the same Expo account in the Expo Go app on your phone.

6. Start the Expo development server if it is not already running:

   `npx expo start`

7. Scan the QR code provided by Expo.

8. The app should open in Expo Go on your phone.
